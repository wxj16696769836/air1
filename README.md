# 中国环境监测数据时空分析项目

## 项目简介

本项目基于中国环境监测数据（PM2.5、SO₂、NO₂浓度等）进行深度时空分析，挖掘污染分布的空间规律与时间变化趋势，为精准防控大气污染、保障公众健康提供数据支撑。

## 技术特色

- 🌍 **地理空间分析**: 使用GeoPandas进行空间数据处理和可视化
- 📊 **时空数据挖掘**: 结合时间序列和空间统计方法
- 🚨 **智能预警系统**: 基于阈值的污染预警机制
- 🎯 **精准预测模型**: 污染浓度预测和趋势分析
- 🖥️ **交互式可视化**: Plotly和Folium创建动态图表

## 数据说明

### 主要污染物指标
- **PM2.5**: 细颗粒物浓度 (µg/m³)
- **PM10**: 可吸入颗粒物浓度 (µg/m³)
- **NO2**: 二氧化氮浓度 (µg/m³)
- **SO2**: 二氧化硫浓度 (µg/m³)
- **CO**: 一氧化碳浓度 (mg/m³)
- **O3**: 臭氧浓度 (µg/m³)
- **AQI**: 空气质量指数

### 地理信息
- **城市**: 监测城市名称
- **经纬度**: 监测站点坐标
- **气象数据**: 温度、湿度、风速、风向等

### 时间信息
- **年份**: 2015-2024
- **月份**: 1-12月
- **季节**: 春夏秋冬
- **星期**: 周一到周日
- **小时**: 0-23时
